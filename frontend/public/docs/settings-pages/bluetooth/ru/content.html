Блютуз модуль для Nucular контроллера

Приложение для Apple: присоединиться к публичному тестированию


Приложение для Android: скачать приложение v1.0.25

Введение

Чтобы подключить блютуз модуль к контроллеру вам понадобится:

  1. Nucular контроллер
  2. Блютуз модуль
  3. Системный кабель (CAN) с питанием 12В
  4. Источник питания для Nucular контроллера
  5. Совместимое устройство Android или Apple

Подключение модуля

Шаг 1: Подключите блютуз модуль к системному кабелю (CAN)

Шаг 2: Включите блютуз на вашем устройстве

Шаг 3: Сопрягите модуль со смартфоном в приложении
Пароль по умолчанию 111122

Файлы

В данный момент файлы сохраняются в папку Downloads (Загрузки).
Android: папка Download (Загрузки)
IPhone: Экспортируйте настройки контроллера чтобы создать папку 'Nucular App' в 'Мой iPhone'

Соединение Bluetooth модуля с Экраном

Подключите CAN кабель из Контроллера в Bluetooth модуль, после этого подключите Bluetooth модуль в Экран дополнительным кабелем PHD-PHD (по середине). Не вставляйте разъемы с силой, пошатайте их в стороны чтобы подключить.

После того как провода подключены можно усадить термоусадку на Bluetooth модуле и стянуть кабели стяжкой вместе.
