USB2CAN module

Install .NET Desktop Runtime 7. Download it from this link.
Install VC runtimes 2015-2022 x64 link.

Download latest version of app: GitHub (archive Windows.ххх.zip).

Extract app, launch exe file. After that connect module to USB port of your PC.

If drivers did not installed automatically then you need to install STM VCOM driver and select driver from list manually.
