Модуль USB2CAN

Установить .NET Desktop Runtime 7. Скачать можно по этой ссылке.
Установить VC runtimes 2015-2022 x64 link.

Далее скачать последнюю версию приложения: GitHub (архив Windows.ххх.zip).

Распаковать, запустить exe файл. После этого подключить модуль напрямую в USB порт компьютера.

Если драйвера не установились автоматически, то необходимо вручную выбрать драйвер stm vcom из списка при установке драйвера.
